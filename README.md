# Lotwise (рабочее название)

[English README](README.md)

Движок корпоративных событий (corporate actions engine) для токенизированных акций в Solana:
нормализует дивиденды, сплиты, слияния и смены тикеров у xStocks / PreStocks / Backpack /
Tessera T-токенов в скорректированные налоговые лоты (adjusted tax lots) + REST API.

Название — рабочее, можно сменить.

## Почему проект существует

Боль найдена вживую при построении P&L-движка для токенизированных акций: корпоративные
события никто не нормализует — ни трекеры, ни универсальные крипто-налоговые сервисы.
В момент сплита, дивиденда, смены тикера или слияния математика кост-бейса ломается молча:
лоты ошибаются, история позиции превращается в числа, которые не защитить в отчёте.

Ниша пустая, тема RWA/токенизация — один из главных трендов экосистемы.

## Что умеет

- **Реестр:** 31 токенизированная акция у 4 эмитентов (Backed/xStocks 16, PreStocks 8,
  Backpack 4, Tessera 3); все минты верифицированы на мейннете (RPC, owner Token-2022,
  decimals сверены). Дивидендный слой: JPMx, KOx, Vx, XOMx, QQQx — классические плательщики
  дивидендов + ETF-брат SPYx, материал для DIVIDEND_ACCRUAL.
- **Схема событий:** 6 типов (SPLIT, DIVIDEND_ACCRUAL, MERGER, TICKER_CHANGE, REDEEM,
  MULTIPLIER_CHANGE), fail-closed валидация, источники у каждого события.
- **Индексатор:** mint/burn/transfer-дельты (Token-2022), fail-closed reconcile между RPC,
  ядовитые лоты отбрасываются, failed-транзакции не дают фантомных дельт.
- **Движок лотов:** FIFO с точной BigInt-пылью; дивидендные начисления per-unit по экс-дате.
- **Цена-кросс-чек:** дневные свечи GeckoTerminal против дат событий, вердикты
  consistent/mismatch/suspicious/inconclusive/no-price-data — для ребейзов и дивидендов
  (математика в raw-единицах, без долларов).
- **REST API + витрина:** /health /tokens /events /multiplier /onchain /lots /accruals
  /crosscheck /summary; страница-отчёт самодостаточна (ноль внешних ресурсов).

## Быстрый старт

```
node scripts/serve.mjs        # → http://127.0.0.1:8787
node --test test/*.test.mjs   # полный сьют
```

Зависимостей нет (Node 24), внешние ключи не нужны — публичный RPC по умолчанию.
Подробности и примеры curl — в [English README](README.md).

## Принципы

- Read-only инфраструктура: свой токен не выпускаем, в протоколы не пишем.
- Честность витрины: числа только из эндпоинтов, неизвестное помечается неизвестным
  (complete:false, excluded+reason, no-price-data), дивиденды не синтезируются из множителей —
  только из явных деклараций эмитента.
- Атомарная запись всего состояния (tmp+fsync+rename), повреждённые файлы карантинятся,
  процесс не умирает — деградирует с флагом.
